== Purpose

This document turns the Knowledge Graph and Semantic Layer design into independently deliverable, GitHub-tracked vertical slices. It deliberately follows the local-wiki reliability work on the current roadmap: authoritative knowledge must be safe, migratable, and syncable before it gains a graph view or semantic assistance.

The GitHub parent issue, https://github.com/Artem535/CppWiki/issues/184[#184], is the planning authority for issue numbers and live status. This document records the intended dependency shape and is updated if the delivery graph materially changes.

== Test Strategy

Each issue validates observable behavior through the highest stable seam available:

* `WorkspaceKnowledgeStore` contract tests prove identical behavior for file and Couchbase Lite storage, including migrations, round trips, deletion/recovery, and conflict preservation.
* editor bridge and page UI tests prove properties, link navigation, and Connections behavior from a user-visible contract.
* Graph View tests prove selected-node details, navigation, edge classification, and filters without asserting a particular force-layout coordinate.
* semantic tests use deterministic provider fixtures and index fixtures; they assert evidence, incremental invalidation, and the absence of authoritative mutations rather than a model's exact floating-point output.

== Release Gates

Phase 1 is complete only when all authoritative knowledge records survive local storage, sync, workspace archive/restore, recoverable trash, and page rename/delete flows without silently losing relations or property values.

Phase 2 is complete only when semantic data can be removed and rebuilt, provider absence leaves normal wiki work intact, and every visible semantic relation has inspectable evidence.

Phase 3 is complete only when all recommendations can be ignored safely and no AI operation can mutate authoritative knowledge without an explicit user action.
