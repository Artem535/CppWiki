== Guardrails

* Do not label deferred work `ready-for-agent`.
* Preserve original issue text and discussion; add a triage comment rather than rewriting history.
* An issue may have both `reframe` and `deferred` when its eventual purpose changes but its work is not next.
* ``Priority'' is reserved for the active frontier after blockers are complete, not for every desirable foundation item.
